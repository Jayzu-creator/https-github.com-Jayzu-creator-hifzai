# HifzAI Privacy Policy

**Effective date:** 22 September 2026

HifzAI is a free Quran reading and memorisation companion. The current release does not require an account, does not sell subscriptions, and does not collect payment information.

## Information we collect

The current release does not collect names, email addresses, account credentials, recordings, contacts, location data, or advertising identifiers.

## Quran content and network access

When a user opens a Surah, HifzAI requests Quran text from the AlQuran Cloud public API. The app is configured to use Wi-Fi for its network features. The API provider may receive the device's network request information needed to return the requested text. Please review the provider's own terms and privacy policy before publishing.

## Microphone and recitation analysis

The current release does not record or upload microphone audio. Recitation analysis is not enabled in this release.

## Children

HifzAI does not knowingly collect personal information from children or adults.

## Changes

If data practices change, this policy will be updated before the relevant feature is released.
